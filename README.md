# Weatherly

A responsive weather dashboard built with HTML, CSS, and vanilla JavaScript. Search for a city or use your current location to see current conditions, an hourly forecast, and a 7-day outlook.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The app uses the free [Open-Meteo](https://open-meteo.com/) weather and geocoding APIs and does not require an API key. Location lookup requires browser permission and a secure context (HTTPS or localhost).

## Features

- Search worldwide locations
- Current conditions, humidity, wind, sunrise, and sunset
- Hourly and 7-day forecasts with precipitation chances
- Celsius and Fahrenheit display
- Responsive layout for desktop and mobile
